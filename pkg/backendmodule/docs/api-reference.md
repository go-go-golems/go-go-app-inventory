# Inventory API Reference

Main routes:

- `POST /api/apps/inventory/chat`
- `GET /api/apps/inventory/ws`
- `GET /api/apps/inventory/api/timeline`
- `GET /api/apps/inventory/api/chat/profiles`
- `GET /api/apps/inventory/api/chat/profile`
- `POST /api/apps/inventory/confirm`
- `GET /api/apps/inventory/docs`
- `GET /api/apps/inventory/docs/{slug}`
